# 오늘의 할 일 (To-Do List)

HTML, CSS, JavaScript만으로 만든 반응형 할 일 관리 웹사이트입니다. 할 일을 추가하고 완료 처리하거나 삭제할 수 있으며, 데이터는 브라우저의 `localStorage`에 자동 저장됩니다.

## 주요 기능

- 할 일 추가, 완료 체크, 삭제
- 전체 / 진행 중 / 완료 항목 필터
- 완료 항목 한 번에 지우기
- 새로고침 후에도 유지되는 `localStorage` 저장
- PC와 모바일에 대응하는 반응형 디자인

## 실행 방법

별도 설치가 필요하지 않습니다.

1. 이 폴더의 `index.html`을 웹 브라우저로 엽니다.
2. 입력창에 할 일을 입력하고 `추가`를 누릅니다.
3. 체크 버튼으로 완료 상태를 바꾸거나 `×` 버튼으로 삭제합니다.

GitHub Pages에서는 이 저장소의 Pages 설정에서 배포 브랜치와 폴더를 선택하면 정적 사이트로 배포할 수 있습니다. 현재 프로젝트에는 배포나 GitHub Push를 수행하지 않았습니다.

## 테스트 방법

1. `index.html`을 열고 할 일을 2~3개 추가합니다.
2. 체크 버튼을 눌러 완료 표시와 진행률이 바뀌는지 확인합니다.
3. `진행 중`, `완료`, `전체` 필터가 각각 올바른 항목을 보여주는지 확인합니다.
4. 삭제 버튼과 `완료 항목 지우기`가 정상 작동하는지 확인합니다.
5. 페이지를 새로고침해도 할 일이 남아 있는지 확인합니다.
6. 브라우저 창을 좁게 줄이거나 모바일 기기에서 열어 레이아웃이 자연스럽게 바뀌는지 확인합니다.

## 파일 구성

- `index.html`: 화면 구조
- `style.css`: 디자인 및 반응형 스타일
- `script.js`: 할 일 관리 기능과 `localStorage` 처리
